# Cycle HUD icons

Generated with the built-in image generator using the supplied moon/cloud reference and matching style. Both are transparent 1254x1254 PNGs with dark outlines and no timer/text.

- cycle-moon-cloud-v1.png: neutral silver/white moon with dark clouds, for countdown to night.
- cycle-sun-cloud-v1.png: gold sun with pale cloud, for countdown to dawn.
- generation.prompts.md: exact prompts and provenance.
- manifest.json: dimensions, alpha sample checks and SHA-256 hashes.

Icons are generated interpretations, not exact screenshot cutouts. Image exterior alpha checked at (0,0)=0 for both. Original cache files preserved. No Roblox upload IDs yet: upload under the intended project owner before wiring; do not fabricate IDs. Render with preserved aspect ratio, not TextLabel emoji. These are cycle icons, not active weather-event badges.

Pair with live WHITE timer text; RED text only in the DAY near-night warning window. Never bake a countdown or warning color into the icon. Native compact timer/switch behavior is described in ../../references/walk-mode-clock-2026-10-04/CLAUDE_PROMPT.md. Phone-sized rendering and Roblox image loading remain unverified.
