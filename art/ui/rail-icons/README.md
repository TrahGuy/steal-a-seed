# Rail icon vector set

Five transparent, icon-only SVG masters for the code-built rail buttons:

- shop.svg — green market stall
- garden.svg — amber raised bed and sprout
- index.svg — blue plant almanac
- inventory.svg — brown satchel
- settings.svg — steel-blue mechanical gear with brass hub

The SVG files are the editable masters. Matching 512px PNG exports are for Roblox
upload. Keep the existing native button slabs, labels, badges and interaction;
these assets replace only the icon drawings.

No text is baked into the icons. All five preserve their button colour
identities and share the same dark outline, cream separation stroke, lighting and
transparent padding. Inspect them at their actual 28–30px rail size before upload.
